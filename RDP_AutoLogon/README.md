# Массовое RDP-подключение через Remmina

Скрипт запускает RDP-подключения через Remmina ко всем компьютерам, указанным в файле со списком адресов.

## 1. Генерация зашифрованного пароля

Перед запуском необходимо зашифровать пароль командой:

```bash
printf '%s' 'пароль администратора' | remmina --encrypt-password
```

После выполнения команда выведет зашифрованную строку.

Полученное значение необходимо вставить в переменную:

```text
ENCRYPTED_PASSWORD
```

Также в скрипте необходимо указать имя пользователя и домен в переменной:

```text
USERNAME
```

Пример формата имени пользователя:

```text
DOMAIN\username
```

> Зашифрованный пароль всё равно следует считать конфиденциальными данными. Не публикуйте его в открытом репозитории.

## 2. Файл `arm.txt`

По умолчанию скрипт считывает адреса из файла `arm.txt`, расположенного рядом со скриптом.

В файле можно указывать:

- IP-адреса;
- доменные имена компьютеров.

Каждый адрес указывается с новой строки.

Пример содержимого файла `arm.txt`:

```text
10.X.X.5
10.X.X.6
computer-01.demo.local
computer-02.demo.local
```


## 3. Подготовка к запуску

Выдайте скрипту право на выполнение:

```bash
chmod +x RDP.sh
```

Запуск со стандартным файлом `arm.txt`:

```bash
./RDP.sh
```

Также можно передать другой файл со списком адресов:

```bash
./RDP.sh hosts.txt
```

После запуска скрипт последовательно откроет отдельное RDP-подключение для каждого IP-адреса или доменного имени из файла.
